# 南宁街头 · 中山路美食街

一个跑在浏览器里的 **一条街**：广西南宁中山路美食街，大约 300 米，按真街的宽度来。
嗦老友粉、饮横州茉莉、逛夜市、砸铺头、招警察——Three.js 里实时渲染，无后端。

> **状态：一条街** · 北段粉店、中段夜市、南段奶茶。旧的朝阳路、邕江、大桥、机械厂不在默认地图里。
> `?stream=1` 仍会进入原来的程序化城市。美术是程序化 PBR，还不是实拍贴图。

## 玩法

| 操作 | 键 |
| --- | --- |
| 移动 | `W` `A` `S` `D` / 方向键 |
| 跑步 | `Shift` |
| 进店买嘢 | `E`（走到骑楼廊下的店面） |
| 砸铺 / 打人 | `Space` |
| 上车 / 下车 | `E`（附近没店时；车在北口护栏外） |

- **任务链**：三个街内委托。食三间老友粉 → 粉饺配糖水 → 夜市烧烤加一杯奶茶。
  买粉要求**不同店**，不能一家刷完。
- **买**：`E` 进店买老友粉、粉饺、横州茉莉奶茶、酸嘢、烧烤……吃东西恢复饱食度。
  夜市摊 18:00 后才出。
- **砸**：`Space` 砸面前的店面。招牌闪红、玻璃飞溅；砸烂后招牌换成「砸烂咗」、
  霓虹熄灭、玻璃变黑——**永久性的**。砸铺涨通缉星。
- **通缉**：★–★★★★★，警察追你。跑到没人看得见你，热度才降。
- **车**：美食街上没有 AI 车流。护栏外的民族大道、桃源路有背景车。主角的车停在北口外面。
- **白话**：路人会自己讲南宁白话，你靠近时会转头看你；通缉高了会喊「唔好动！」。

## 画面

- 程序化 **PBR 材质**：青砖、红砖、混疑土、沥青、石灰墙、刷钢——每种都由
  Sobel 从高度场推导法线贴图，砖缝和骨料是真的凹凸，不是贴图
- **Bloom + ACES 色调映射**：霓虹和灯笼真的发光并溢到墙上
- 屋顶杂物：不锈钢水塔、空调外机、晾衣架、天线（每栋楼都随机）
- 立面：空调外机、落水管、防盗网、竖招牌、满洲窗
- 按材质合批：墙体、骑楼柱、摊位各自合并，招牌按店一张贴图
- 半城绿树半城楼：榕树有伞形树冠、板根和气生根

## 场景

- **中山路**：z −150..+150，街面 9 m，两侧骑楼廊下各 2.4 m（高 0.15 m），店铺进深 8 m
- **横巷**：街中 z≈0 西侧，宽 4 m、深 15 m，死胡同
- **分段**：北段粉 / 粉饺 / 糖水，中段夜市（约 24 个摊，18:00 后），南段奶茶 / 螺蛳粉 / 凉茶 / 士多
- **约 36 间门面**。能核对到的用真名（复记老友粉、中山粉饺、梁记卷筒粉等）；店主要求放上的舒记、荣记、阿婆酸嘢、横州茉莉、甘家界也在街上。其余是本地口味的铺名
- 北口民族大道、南口桃源路用护栏封住，外面的车只做背景
- 主角是程序化的低模人物（白大褂、灰背心、工装短裤、人字拖、黑框眼镜），定义在 `src/characters/`，换衣服不改玩法代码

## 技术

- **Three.js r160** + TypeScript + Vite，零后端
- 基于 [depixeled-chris/gta7](https://github.com/depixeled-chris/gta7)（MIT）改造，
  沿用了它的碰撞 / 空间网格 / 跟随相机 / 车辆物理 / 通缉系统 / 音频合成 / 移动端适配
- 南宁专属层在 `src/nanning/`（数据 · 布局 · 店铺 · 任务 · 造景）
  和 `src/session/nanningSession.ts`（从 `main.ts` 拆出的街内会话）
- `npm test` · `npm run smoke` · `node scripts/nn-smoke.mjs`
