# 南宁街头 · Nanning GTA

一个跑在浏览器里的 **GTA 式开放世界街区**，场景是广西南宁的邕州古城与机械厂文创园。
买奶茶、吃老友粉、逛夜市、砸铺子、招警察——全部在 Three.js 里实时渲染，无后端。

> **状态：v0.3** · 主角是穿黑三件套的程序化人体，汽车是放样车体，窗洞是真的凹进去的。
> 跳跃、重力、空中转向都有。美术 100% 代码生成，**零二进制资源**。

**在线试玩** → https://cst4j70zyx62f.space.mcode.cn

## 玩法

| 操作 | 键 |
| --- | --- |
| 移动 | `W` `A` `S` `D` / 方向键 |
| 跑步 | `Shift` |
| 进店买嘢 | `E`（走到骑楼廊下的店面） |
| 砸铺 / 打人 | `Space` |
| 上车 / 下车 | `E`（附近没店、也没欠你钱的人时） |
| 收租 | `E`（走到讨债 NPC 面前） |

- **任务链**：六个委托，一个接一个解锁，任务面板在左上，路点有金色光柱和方位箭头。
  嗍粉 → 奶茶自由 → 酸嘢一条街 → 夜市收租 → 电瓶车飙车 → 拆铺行动。
  买粉和买奶茶要求**不同店**，不能一家刷完。
- **收租**：街上站着三个欠租的 NPC，走过去按 `E` 收钱，他们会道谢然后走开。
- **买**：`E` 进店买老友粉、茉莉花奶茶、酸嘢、凉茶、芝麻糊……吃东西恢复饱食度。
- **砸**：`Space` 砸面前的店面。招牌闪红、玻璃飞溅；砸烂后招牌换成「砸烂咗」、
  霓虹熄灭、玻璃变黑——**永久性的**。砸铺涨通缉星。
- **通缉**：★–★★★★★，警察追你。跑到没人看得见你，热度才降。
- **电瓶车**：五羊小电驴，质量只有车的 1/8，窄、快、掉头贼猛。停在朝阳路。
- **白话**：路人会自己讲南宁白话，你靠近时会转头看你；通缉高了会喊「唔好动！」。

## 人物

主角是**穿黑三件套的人**，不是胶囊。程序化建模，没有外部模型文件：

- 7 头身比例，肩宽 0.40 米、腰围收进去、下摆外放——**西装剪影的关键是收腰，不是加宽**
- **戗驳头**：从肩到腰的 V 形，是「一个人在穿西装」和「一个黑筒上长了个头」的分界
- 白色衬衫、领带、马甲三颗扣、法式袖口、西裤烫线、黑色牛津鞋
- 侧分背头：哑光材质 + 扫过去的顶部体积 + 分缝线（之前用亮面材质，像摩托车头盔）
- 走跑循环：肩胯反向旋转、膝盖只向后弯、跑步前倾、起步有髋部起伏
- 侧身移动时身体会倾斜
- **跳跃**：起跳屈膝收腿、下落伸腿、落地缓冲；空中转向权限只有 35%

## 画面

- 程序化 **PBR 材质**：青砖、红砖、混疑土、沥青、石灰墙、刷钢——每种都由
  Sobel 从高度场推导法线贴图，砖缝和骨料是真的凹凸，不是贴图
- **Bloom + ACES 色调映射**：霓虹和灯笼真的发光并溢到墙上
- 屋顶杂物：不锈钢水塔、空调外机、晾衣架、天线（每栋楼都随机）
- 立面：空调外机、落水管、防盗网、竖招牌、满洲窗
- **窗洞是真的凹进去**：玻璃退后 0.22 米，窗台外挑、窗楣压顶、竖挺凸出、洞口有侧壁——
  一扇画在平面上的窗是贴纸，有投影的窗才是窗
- 楼体竖向钢柱外凸，带柱头柱脚
- 车身是**放样**出来的：沿车长切一串截面蒙皮，低鼻、抬起的机盖线、斜风挡、
  内收的玻璃座舱、短尾厢。轮胎有胎面、轮辋、五根辐条和刹车盘
- 按材质合批：整片城区约 20 个 draw call，不是每楼一个
- 半城绿树半城楼：榕树有伞形树冠、板根和气生根

## 场景

- **邕州古城**：中山路骑楼步行街、钟鼓楼广场、中山路夜市、金狮巷 / 银狮巷、水街、邕江、南宁大桥
- **机械厂文创园**：红砖锯齿厂房、安全黄外挂钢楼梯、工业钢窗——跟老城完全相反的一套建筑语言
- 全部街区、店铺、招牌、白话台词都是虚构的，**没有使用任何真实注册商标**

## 技术

- **Three.js r160** + TypeScript + Vite，零后端
- 基于 [depixeled-chris/gta7](https://github.com/depixeled-chris/gta7)（MIT）改造，
  沿用了它的碰撞 / 空间网格 / 跟随相机 / 车辆物理 / 通缉系统 / 音频合成 / 移动端适配
- 南宁专属层在 `src/nanning/`（数据 · 布局 · 店铺系统 · 造景）
  和 `src/render/nnArch.ts`（按实拍照片还原的建筑生成器）
- `npm test` 164 个单测 · `npm run smoke` 无头渲染自测

## 开发

```bash
npm install
npm run dev        # 开发
npm test           # 164 个单元测试
npm run build      # 类型检查 + 产物
OUT=s.png node scripts/nn-smoke.mjs   # 无头渲染自测 + 截图
```

### 给要改这个项目的人（尤其是 AI agent）

**先读 [`AGENTS.md`](./AGENTS.md)。** 里面是这个项目的架构地图、必须守住的规矩
（渲染合批、UV 缩放、frameTime 下限、跳跃输入为什么是电平触发），
以及 URL 调试参数 `?t=` `?hud=0` `?seed=`。

一句话版本：**这个项目没有外部美术资源，所有模型都是代码生成的。改任何东西之前先跑一遍
`npx tsc --noEmit && npx vitest run`，改完用 `scripts/_shot.mjs` 拍一张看看，别凭想象判断。**

### 贡献
